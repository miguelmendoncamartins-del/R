## Codificação de Jogos
_matéria: `codificacao-jogos`_

### Janeiro (Aulas 01 a 02)
**Capacidades desenvolvidas**
- Reconhecer os procedimentos de instalação e configuração do ambiente de desenvolvimento (IDE)
- Executar instalação e configuração da IDE (VSCode)

**Conteúdos trabalhados**
- Linguagem de programação para jogos: histórico, instalação, configuração do Ambiente de Desenvolvimento Integrado (IDE), variáveis de ambiente, extensões e teste básico ("Hello World")

### Fevereiro (Aulas 03 a 06)
**Capacidades desenvolvidas**
- Reconhecer as linguagens de programação utilizadas no desenvolvimento de jogos
- Reconhecer diferentes tipos e formatos de dados e arquivos
- Reconhecer especificações técnicas definidas no projeto (GDD)
- Reconhecer o processo de renderização de elementos multimídia

**Conteúdos trabalhados**
- Sintaxe e ferramentas de linguagens (C#, GDScript, C++)
- Formatos de dados para acesso/armazenamento (JSON, XML, Binários)
- Produção de jogos digitais (Pré-produção e Produção): requisitos funcionais vs. não funcionais extraídos do Game Design Document (GDD)
- Pipeline de renderização e exibição de assets (sprites, texturas)

### Março (Aulas 07 a 10)
**Capacidades desenvolvidas**
- Reconhecer os pilares e os níveis hierárquicos de segurança da informação
- Reconhecer e aplicar processos de depuração (debugging) e tratamento de erros
- Aplicar técnicas de conversão e manipulação de dados e arquivos externos

**Conteúdos trabalhados**
- Segurança da Informação: pilares (Confidencialidade, Integridade e Disponibilidade) aplicados a sistemas de login e modelagem de permissões/níveis de acesso ao banco de dados
- Ferramentas de Depuração: rastreamento de erros em código via VSCode Debugger (Watch, Call Stack)
- Manipulação de Dados: leitura e conversão de arquivos externos (JSON) em objetos instanciáveis na engine sem a necessidade de recompilação

### Abril (Aulas 11 a 14)
**Capacidades desenvolvidas**
- Aplicar técnicas e métodos de desenvolvimento utilizando Programação Orientada a Objetos (POO) e Programação Orientada a Componentes
- Aplicar linguagem de programação no uso de frameworks e integração multimídia

**Conteúdos trabalhados**
- Programação Orientada a Objetos (POO): criação de classe base (ex: inimigos), instanciação e encapsulamento
- Programação Orientada a Componentes: desacoplamento de lógicas (movimento, saúde) usando nós/componentes modulares
- Frameworks: integração e leitura de documentação técnica para bibliotecas externas (áudio, partículas)
- Integração Multimídia: disparadores (triggers) para áudio e animações engatilhadas pelas ações dos personagens

### Maio (Aulas 15 a 18)
**Capacidades desenvolvidas**
- Aplicar metodologias ágeis e resolução de problemas técnicos
- Aplicar boas práticas de desenvolvimento (Clean Code) e documentação de projetos com rastreabilidade

**Conteúdos trabalhados**
- Metodologia Ágil: simulação de Sprint com quadro Kanban focando na segurança do fluxo de trabalho
- Resolução de Problemas: live coding em grupo para depuração de problemas complexos de lógica (ex: conflitos de colisão)
- Boas Práticas / Clean Code: refatoração de código monolítico, padronização de nomenclatura, princípio DRY (Don't Repeat Yourself) e modularização
- Documentação: escrita de comentários técnicos (Docstrings) e criação de guias de referência para rastreabilidade

### Junho (Aulas 19 a 22)
**Capacidades desenvolvidas**
- Aplicar boas práticas de segurança da informação no código
- Aplicar estruturas de dados avançadas (Grafos e Árvores de Decisão) para lógica e IA

**Conteúdos trabalhados**
- Segurança da Informação: validação de inputs de usuário para prevenir injeções maliciosas
- Grafos em Jogos Digitais: navegação de NPCs via waypoints e algoritmos de busca em grafos para rastreamento de movimento/mecânicas
- Árvores de Decisão: introdução à IA de inimigos/NPCs através de condicionais aninhadas e máquinas de estado ("Atacar se ver o player; senão, patrulhar")
